# Лаба 8
## Відповіді на контрольні питання:

1. Чим інтерфейс Set відрізняється від інтерфейсів Collection та List?
-   Відповідь:
-	Set:
     -	Множина, яка не допускає дублікатів.
     -	Елементи не впорядковані (або впорядковані залежно від реалізації, наприклад, TreeSet).
-	Collection:
     -	Базовий інтерфейс для всіх колекцій у Java.
     -	Не має специфічних обмежень щодо унікальності чи порядку елементів.
-	List:
     -	Колекція, яка дозволяє дублікати.
     -	Елементи впорядковані та мають індекси.

2. Чим HashSet відрізняється від TreeSet?
-   Відповідь:
-	HashSet:
     -	Реалізований на основі хеш-таблиці.
     -	Не гарантує порядок елементів.
     -	Швидкий доступ до елементів (O(1) у середньому).
-	TreeSet:
     -	Реалізований на основі дерева (Red-Black Tree).
     -	Елементи впорядковані природним порядком або за переданим Comparator.
     -	Доступ до елементів повільніший (O(log n)).

3. Що таке хешування, хеш, хеш-код, хеш-функція?
-   Відповідь:
-	Хешування: Процес перетворення об’єкта в числове значення (хеш-код).
-	Хеш: Числове значення, що представляє об’єкт.
-	Хеш-код: Результат роботи хеш-функції.
-	Хеш-функція: Алгоритм, що обчислює хеш-код на основі властивостей об’єкта.

4. Яким вимогам має відповідати коректна хеш-функція?
-   Відповідь:
-	Однакові об’єкти повинні мати однаковий хеш-код.
-	Різні об’єкти можуть мати однаковий хеш-код (колізії допускаються, але мають бути рідкісними).

5. Які властивості притаманні хорошій хеш-функції?
-   Відповідь:
-	Мінімальна кількість колізій.
-	Рівномірний розподіл значень хеш-кодів.
-	Висока швидкість обчислення.

6. Якими критеріям мають відповідати об’єкти для того, щоб посилання на них можна було зберігати у HashSet?
-   Відповідь:
-	Коректно перевизначені методи hashCode() та equals().
-	Методи повинні узгоджуватись: якщо два об’єкти рівні (equals()), то їхні хеш-коди повинні бути однаковими.

7. Які є переваги/недоліки використання HashSet у порівнянні з TreeSet?
-   Відповідь:
-	HashSet:
     -	Переваги: швидкість операцій (O(1) у середньому).
     -	Недоліки: не гарантує порядок елементів.
-	TreeSet:
     -	Переваги: впорядкованість елементів.
     -	Недоліки: повільніші операції (O(log n)).

8. Чим поняття size відрізняється від capacity? Чи може size бути більший за capacity?
-   Відповідь:
-	size: Поточна кількість елементів у колекції.
-	capacity: Максимальна кількість елементів, яку колекція може вмістити без розширення.
-	size не може бути більшим за capacity.
-	capacity може бути більшим за size до досягнення ліміту.

9. Що таке load factor та на що і як він впливає?
-   Відповідь:
-	Load factor — коефіцієнт завантаження, який визначає, коли потрібно розширити хеш-таблицю.
-	Вплив: якщо розмір перевищує (load factor × capacity), хеш-таблиця розширюється.

10. Що таке асоціативний масив? Чим ключ відрізняється від значення?
-   Відповідь:
-	Асоціативний масив: Структура даних, де кожне значення зберігається у парі з унікальним ключем.
-	Ключ: Унікальний ідентифікатор для доступу до значення.
-	Значення: Дані, асоційовані з ключем.

11. Чи може в асоціативному масиві зберігатись кілька однакових ключів або однакових значень?
-    Відповідь:
-	Однакові ключі — не можуть.
-	Однакові значення — можуть.

12. До яких наслідків може привести зберігання неімутабельних об’єктів у HashSet, у HashMap в якості ключа та у HashMap в якості значення?
-    Відповідь:
-	Якщо об’єкт змінюється після додавання:
     -	У HashSet можуть виникнути проблеми з пошуком і видаленням.
     -	У HashMap ключ може стати недоступним через зміну його хеш-коду.

13. Чи можуть об’єкти без інтерфейсу Comparable зберігатись у TreeMap?
-    Відповідь:
-	Ні, об’єкти повинні бути Comparable або TreeMap має отримати Comparator під час створення.

14. Чи можуть об’єкти без інтерфейсу Comparable зберігатись у HashMap? Чи взагалі впливає на щось наявність у об’єктів інтерфейсу Comparable при зберіганні у HashMap?
-    Відповідь:
-	Об’єкти без Comparable можуть зберігатись у HashMap, оскільки порядок не важливий.
-	Наявність Comparable не впливає на роботу HashMap, оскільки цей інтерфейс використовується для сортування, а не для хешування.
