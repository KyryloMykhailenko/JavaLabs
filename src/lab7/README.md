# Лаба 7 
## Відповіді на контрольні питання:

1. Для чого призначений Collections Framework?
-  Відповідь:
   - Collections Framework — це набір класів і інтерфейсів у Java, який забезпечує стандартні структури даних (списки, множини, черги тощо) і алгоритми для роботи з ними (сортування, пошук, перетворення).
-  Призначення:
   - Спрощує обробку структур даних.
   - Забезпечує ефективність і узгодженість API.
   - Полегшує код через використання узагальнень (Generics).
2. В чому полягає різниця між масивами та колекціями?
-   Масиви:
    - Фіксована довжина.
    - Підтримують лише один тип даних.
    - Не мають методів для маніпуляції даними (наприклад, додавання, видалення).
-   Колекції:
    - Динамічна довжина (можуть змінюватись у процесі виконання).
    - Підтримують різні типи даних через узагальнення.
    - Надають методи для роботи з елементами (додавання, видалення, сортування).
3. Які особливі властивості є у списків порівняно з іншими типами колекцій?
    - Списки (List) впорядковані — елементи мають індекси.
    - Дозволяють зберігати дублікати.
    - Забезпечують доступ до елементів через їх індекси.
    - Підтримують методи для роботи з індексами (get, set, indexOf).
4. Чим списки відрізняються від масивів?
-   Масиви:
    - Фіксований розмір.
    - Необхідно явно обробляти операції додавання, видалення.
-   Списки:
    - Динамічна довжина.
    - Підтримують додавання, видалення і вставку елементів за допомогою методів (add, remove).
    - Більша функціональність завдяки Collections Framework.
5. Чим ArrayList відрізняється від LinkedList? Який з них у яких випадках краще використовувати?
-   ArrayList:
    - Реалізований на основі динамічного масиву.
    - Швидкий доступ за індексом (O(1)).
    - Додавання/видалення елементів у середину чи початок — повільне (O(n)).
    - Підходить для операцій, де потрібен частий доступ до елементів за індексом.
-   LinkedList:
    - Реалізований на основі зв’язаного списку.
    - Повільний доступ за індексом (O(n)).
    - Швидке додавання/видалення елементів на початку чи в середині (O(1) для операцій через ітератор).
    - Підходить для операцій, де часто додаються чи видаляються елементи.
6. Що таке Iterator? В чому полягають переваги використання ітератора у порівнянні з класичним циклом?
-   Відповідь:
    - Iterator — це інтерфейс, який забезпечує послідовний доступ до елементів колекції без розкриття її внутрішньої реалізації.
-   Переваги ітератора:
    - Працює однаково для всіх типів колекцій.
    - Дозволяє видаляти елементи під час ітерації без ризику виклику помилки ConcurrentModificationException.
    - Зрозуміліший та чистіший код для ітерації.
7. Що таке типізовані та нетипізовані колекції?
-   Типізовані колекції (Generic Collections):
    - Задається тип даних, який може зберігатися в колекції.
-   Переваги:
    - Захист від помилок часу виконання (компілятор перевіряє типи).
    - Спрощує роботу з даними, оскільки не потрібне явне приведення типів.
-   Нетипізовані колекції:
    - Застарілий підхід, де колекція може містити об’єкти будь-якого типу.
-   Недоліки:
    - Необхідність явного приведення типів.
    - Можливість виникнення помилок під час виконання.
8. Для чого потрібен інтерфейс RandomAccess?
    - Інтерфейс RandomAccess використовується для маркування колекцій, які забезпечують швидкий доступ до елементів за індексом (наприклад, ArrayList).
    - JVM може використовувати цю інформацію для оптимізації алгоритмів, що працюють з такими колекціями.
9. Чим Collection відрізняється від Collections?
-   Collection:
    - Інтерфейс, який є базовим для всіх колекцій у Java (List, Set, Queue).
-   Collections:
    - Утилітний клас, який містить статичні методи для роботи з колекціями (наприклад, сортування, перемішування, створення незмінюваних колекцій).
