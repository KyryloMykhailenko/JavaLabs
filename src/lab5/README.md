# Лаба 5

## Відповіді на контрольні питання:

1. Порівняйте та назвіть переваги та недоліки таких методів сортування: сортування бульбашкою, сортування вибором, сортування вставкою.
-   Сортування бульбашкою:
    -	Переваги: Легко реалізувати, добре підходить для навчання алгоритмів сортування.
    -	Недоліки: Повільний для великих масивів через високу кількість порівнянь і обмінів елементів.
   Сортування вибором:
    -	Переваги: Простий для реалізації, мінімальна кількість обмінів (залежить лише від кількості елементів).
    -	Недоліки: Низька ефективність для великих даних, навіть у частково відсортованих масивах.
   Сортування вставкою:
    -	Переваги: Швидке для майже відсортованих даних, стабільний алгоритм, менше переміщень елементів у порівнянні з бульбашковим сортуванням.
    -	Недоліки: Повільний для великих невідсортованих масивів.

2. Оцініть кожен з методів відповідно до наступних критеріїв:
-   Час роботи:
    -	Бульбашка: O(n2)O(n^2)O(n2) для всіх випадків.
    -    Вибір: O(n2)O(n^2)O(n2) для всіх випадків.
    -	Вставка: O(n2)O(n^2)O(n2) у гіршому випадку, O(n)O(n)O(n) у найкращому (коли масив майже відсортований).
-   Потреби у додатковій пам’яті:
    -    Усі три методи мають потреби O(1)O(1)O(1), оскільки вони сортують масив на місці.
-   Стабільність:
    -    Бульбашка: Стабільний.
    -    Вибір: Нестабільний (елементи з однаковим значенням можуть змінювати порядок).
    -    Вставка: Стабільний.
-   Додаткові критерії:
    -    Простота реалізації.
    -    Чутливість до вже відсортованих даних.
    -    Кількість порівнянь та обмінів.

3. Який випадок є найкращим або найгіршим для роботи цих алгоритмів?
-   Сортування бульбашкою:
    -    Найкращий: Масив уже відсортований (одна перевірка O(n)O(n)O(n)).
    -    Найгірший: Масив у зворотному порядку (O(n2)O(n^2)O(n2)).
-   Сортування вибором:
    -    Найкращий і найгірший: Незалежно від початкового стану масиву O(n2)O(n^2)O(n2), оскільки алгоритм завжди виконує однакову кількість порівнянь.
-   Сортування вставкою:
    -    Найкращий: Частково відсортований масив (O(n)O(n)O(n)).
    -    Найгірший: Масив у зворотному порядку (O(n2)O(n^2)O(n2)).
-   Метод з найкращим результатом:
    -    Для майже відсортованих масивів: сортування вставкою.
    -    Для зворотного порядку всі три методи працюють повільно, але вибір буде дещо ефективнішим через мінімальну кількість обмінів.

4. Що означають позначення O(1), O(n), O(n^2)?
-    O(1)O(1)O(1): Час виконання не залежить від розміру вхідних даних (константний час). Наприклад, доступ до елементу масиву за індексом.
-    O(n)O(n)O(n): Час виконання пропорційний розміру вхідних даних. Наприклад, простий перебір усіх елементів масиву.
-    O(n2)O(n^2)O(n2): Час виконання пропорційний квадрату розміру вхідних даних. Наприклад, вкладені цикли для порівняння кожної пари елементів.
-   Ці позначення описують асимптотичну складність алгоритму та показують, як змінюється час виконання залежно від розміру вхідних даних.
