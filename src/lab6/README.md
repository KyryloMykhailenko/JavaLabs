# Лаба 6

## Відповіді на контрольні питання:

1. Що таке immutable об’єкт? Для чого об’єкти класу String зробили імутабельними? Чому клас String задекларований як final?
-   Відповідь:
    -    Immutable об’єкт — це об’єкт, стан якого не можна змінити після створення.
   Об’єкти класу String зробили імутабельними, оскільки це:
    -    Забезпечує безпеку та потокобезпечність, особливо коли рядки використовуються у багатопотокових програмах.
    -    Оптимізує використання пам’яті завдяки пулу рядків (String Pool), де однакові рядки зберігаються як один об’єкт.
    -    Клас String задекларований як final, щоб заборонити наслідування. Це забезпечує незмінність, адже підкласи могли б змінити поведінку та порушити імутабельність.

2. Що таке регулярні вирази? Наведіть приклади регулярних виразів.
-   Відповідь:
    -    Регулярні вирази (Regular Expressions) — це шаблони, які використовуються для пошуку, заміни або перевірки відповідності рядків певним умовам.
-   Приклади:
    -    \d+ — одна або більше цифр.
    -    [a-zA-Z]+ — одна або більше літер латинського алфавіту.
    -    ^Hello — рядок, що починається з "Hello".
    -    \bword\b — слово "word", яке стоїть окремо.
    -    \s+ — одна або більше пропусків.

3. В чому полягає різниця між оператором «==» та методом «equals()»?
-   Відповідь:
-   Оператор ==:
    -    Порівнює посилання (адреси в пам’яті) для об’єктів.
    -    Для примітивних типів порівнює їх значення.
-   Метод equals():
    -    Використовується для логічного порівняння значень об’єктів (за реалізацією цього методу у відповідному класі).
-  Різниця:
    -    == перевіряє, чи це один і той самий об’єкт.
    -    equals() перевіряє, чи рівні значення об’єктів (для класу String, наприклад, це перевірка вмісту рядків).

4. Для чого потрібні класи StringBuilder та StringBuffer?
-   Відповідь:
    -    Класи StringBuilder та StringBuffer використовуються для створення змінюваних (mutable) рядків.
-   Відмінності:
    -    StringBuilder: Швидший, але не потокобезпечний. Використовується у програмах, де не потрібна синхронізація.
    -    StringBuffer: Повільніший, але потокобезпечний завдяки синхронізації методів.

5. Яким чином простіше всього прибрати пробіли на початку та кінці об’єкту String?
-   Відповідь:
    -    Використати метод trim().
   String trimmed = myString.trim();
    -    Метод видаляє всі пробіли на початку та в кінці рядка, але не змінює пробіли між словами.
