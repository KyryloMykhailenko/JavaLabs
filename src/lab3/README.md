# Лаба 3

## Відповіді на контрольні питання:

1.  Що таке структурне програмування?
-    Відповідь: Структурне програмування — це парадигма програмування, яка базується на використанні трьох основних конструкцій: послідовність, розгалуження і цикли. Цей підхід передбачає, що програма розбивається на блоки з чіткою структурою для полегшення розуміння, модифікації та підтримки коду.
2.  Назвіть основні конструкції структурного програмування.
-    Відповідь: Основні конструкції структурного програмування — це:
     -	Послідовність (лінійне виконання команд одна за одною).
     -	Розгалуження (умовні оператори, як-от if, if-else, switch).
     -	Цикли (ітеративні конструкції, такі як for, while, do-while).
3.  Назвіть основні принципи структурного програмування.
-    Відповідь: Основні принципи структурного програмування:
     - Принцип "розділяй і володарюй" (поділ програми на менші модулі).
     - Використання трьох базових конструкцій: послідовність, розгалуження та цикл.
     -	Відмова від використання неконтрольованих переходів (наприклад, GOTO).
     -	Кожна функція або процедура повинна мати лише одну точку входу і виходу.
4.  Поясніть, чому в більшості мов програмування не радять використовувати оператор GOTO, а в мові Java його взагалі немає?
-    Відповідь: Оператор GOTO ускладнює розуміння і відстеження виконання програми, що може призвести до так званого "спагеті-коду". Це робить програму важкою для підтримки і налагодження. У мові Java його взагалі немає, оскільки Java орієнтується на структурний і об'єктно-орієнтований підходи, які забезпечують кращу організацію коду.
5.  Що таке спагеті-код?
-    Відповідь: Спагеті-код — це код із заплутаною логікою, в якому важко відстежувати послідовність виконання. Він виникає через неконтрольоване використання переходів (наприклад, GOTO), що робить програму важкою для розуміння, налагодження і підтримки.
6.  Що таке проектування зверху-вниз? В чому його переваги?
-   Відповідь: Проектування зверху-вниз — це метод розробки програм, за якого спочатку визначають загальну структуру програми, а потім поступово деталізують її окремі частини. Переваги цього методу включають кращу організацію процесу розробки, легше планування, а також полегшену підтримку і тестування окремих модулів.
7.  Що таке область видимості ідентифікатора?
-    Відповідь: Область видимості ідентифікатора — це частина програми, в якій можна звертатися до змінної, функції чи іншого об'єкта за її ім'ям. У Java є такі області видимості, як глобальна (клас), локальна (функція, блок) та область параметрів методу.
8.  Що таке блок? Як блоки впливають на область видимості?
-    Відповідь: Блок — це частина коду, обмежена фігурними дужками {}, яка визначає локальну область видимості. Змінні, оголошені всередині блоку, видимі тільки всередині цього блоку і недоступні поза ним.
9.  Наведіть приклади, у яких випадках краще використовувати наступні оператори та конструкції:
-	if: Коли необхідно виконати певну дію тільки за умови істинності певного виразу.
-    if-else: Коли потрібно виконати одну з двох можливих дій в залежності від істинності умови.
-    ланцюги if-else if -else if...: Коли є кілька взаємовиключних умов і потрібно обрати одну з них.
-    switch: Коли є фіксована кількість можливих значень змінної, і для кожного значення потрібно виконати різну дію.
-	тернарна умовна операція ?:: Коли потрібно коротко записати просту умову, яка повертає одне з двох значень.
10. Наведіть приклади, у яких випадках краще використовувати наступні оператори та конструкції:
-	while: Коли кількість ітерацій не відома заздалегідь, і цикл має продовжуватися, поки умова істинна.
-	do-while: Коли потрібно гарантовано виконати тіло циклу хоча б один раз перед перевіркою умови.
-	for: Коли кількість ітерацій відома заздалегідь (наприклад, для перебирання елементів масиву).
11.  Чим оператор break відрізняється від оператора continue?
- Відповідь: break повністю зупиняє виконання циклу і виходить з нього, тоді як continue припиняє поточну ітерацію і переходить до наступної.
12.  Навіщо у мові Java є мітки, якщо немає goto?
- Відповідь: Мітки в Java дозволяють керувати потоком виконання у вкладених циклах. Вони використовуються разом із операторами break або continue, щоб вийти з кількох рівнів циклів або перейти до наступної ітерації конкретного циклу.
13.  До якого результату призведе виконання наступного фрагменту коду? Перевірте. Поясніть.
-    boolean a = false;
     boolean b = false;        
     if (a = false) {
     System.out.println("a is false");
     }
     if (b = true) {
     System.out.println("b is true");
     }
     if (a = b) {
     System.out.println("a = b");
     }
-    Відповідь:
     a is false
     b is true
     a = b
-    Пояснення: Оператор присвоєння = використовується замість порівняння ==. Тому в першому if значення a присвоюється false, у другому if значення b стає true, а у третьому a = b робить обидві змінні рівними true.
14. До якого результату призведе виконання наступного фрагменту коду? Перевірте. Поясніть.
    int a = 1;
    a++;
    ++a;        
    switch(a) {
    case 1: System.out.println("1");
    case 2: System.out.println("2");
    case 3: System.out.println("3");
    case 4: System.out.println("4");            
    }
-    Відповідь:
    4
-    Пояснення: Після операцій інкременту значення a стає рівним 4. Оскільки в switch відсутні break, виконується тільки відповідний блок case 4.
15. До якого результату призведе виконання наступного фрагменту коду (true/false)? Перевірте. Поясніть.
-   double sum = 0;                
    for(int i=1; i<10; i++) {
    sum = sum + 1/i;
    }
    System.out.println(sum > 1);
    Відповідь:
    False
    Пояснення: Вираз 1/i — це операція цілочисельного ділення, і всі значення результатів дорівнюють 0 (окрім першого). Щоб отримати правильний результат, необхідно виконати ділення з плаваючою комою: 1.0 / i.
